The four questions:

  1. Gender over time: How has the share of female laureates changed by decade and by category?
  2. Brain drain (join/compare): Which countries “lost” the most laureates, meaning laureates born there but awarded while affiliated with an institution in another country, and what is each country’s net gain or loss?
  3. Age at award: How old are laureates when they win, how does that differ by category, and has it changed over time?
  4. Institutions: Which institutions are affiliated with the most laureates, and in which fields?

Approach Potential Challenges

I get each laureate from the paginated /laureates endpoint (cycling through offset and limit until I get the total in meta$count) and interpret the response with jsonlite, but keep it as a nested list. Then I walk the nesting in purrr and create three tidy tables at different grains: one row per laureate, one row per laureate-prize, and one row per laureate-prize-affiliation. These tables are filtered, grouped, or joined on laureate_id to answer each question. The raw JSON is cached locally so the document renders quickly and does not hit the API repeatedly.

Potential Challenges

The main problem is the nesting: a laureate can win more than once, and a prize can have multiple affiliations, so flattening naively either loses data or duplicates rows. Also, the fields are inconsistent across records: organizations don’t have gender or birth data, some older laureates have no affiliation, and some dates are incomplete, so I use a safe accessor that returns NA instead of erroring and filter out missing values per question. Place names change over time (a birthplace may have been in a country that no longer exists), so I compare the countryNow fields and not the historical names. Finally, institution names aren’t standardized (different campuses or renamed institutes count separately), and the API is paginated and rate-friendly, so I add a short pause between requests and cache results.

Retrieving the JSON

The API is paginated (offset and limit), and the meta$count field in the response tells us the total number of laureates. I loop over the pages and cache the raw result locally so re-rendering does not hit the API every time.

base_url   <- "https://api.nobelprize.org/2.1/laureates"
page_size  <- 100
cache_file <- "nobel_laureates_raw.rds"

if (file.exists(cache_file)) {
  laureates <- readRDS(cache_file)
} else {
  # First request just to learn the total number of laureates
  first <- fromJSON(sprintf("%s?offset=0&limit=%d", base_url, page_size),
                    simplifyVector = FALSE)
  total   <- as.integer(first$meta$count)
  offsets <- seq(0, total - 1, by = page_size)

  pages <- map(offsets, function(o) {
    Sys.sleep(0.3)  # be polite to the API
    fromJSON(sprintf("%s?offset=%d&limit=%d", base_url, o, page_size),
             simplifyVector = FALSE)$laureates
  })

  laureates <- list_flatten(pages)
  saveRDS(laureates, cache_file)
}

Tidying the JSON into data frames

I build three tidy tables from the nested list:

  • laureates_tbl: one row per laureate (person or organization)
  • prizes_tbl: one row per laureate per prize (some people won twice)
  • affil_tbl: one row per laureate per prize per affiliation
# 1. One row per laureate
laureates_tbl <- map_dfr(laureates, function(l) tibble(
  laureate_id       = g(l, "id"),
  name              = coalesce(g(l, "knownName", "en"), g(l, "orgName", "en")),
  type              = if (!is.null(l$orgName)) "organization" else "person",
  gender            = g(l, "gender"),
  birth_date        = g(l, "birth", "date"),
  birth_country     = g(l, "birth", "place", "country", "en"),
  birth_country_now = g(l, "birth", "place", "countryNow", "en")
))

# 2. One row per laureate-prize
prizes_tbl <- map_dfr(laureates, function(l) {
  map_dfr(l$nobelPrizes %||% list(), function(p) tibble(
    laureate_id = g(l, "id"),
    award_year  = as.integer(g(p, "awardYear")),
    category    = g(p, "category", "en"),
    portion     = g(p, "portion")
  ))
})

# 3. One row per laureate-prize-affiliation
affil_tbl <- map_dfr(laureates, function(l) {
  map_dfr(l$nobelPrizes %||% list(), function(p) {
    map_dfr(p$affiliations %||% list(), function(a) tibble(
      laureate_id       = g(l, "id"),
      award_year        = as.integer(g(p, "awardYear")),
      category          = g(p, "category", "en"),
      institution       = coalesce(g(a, "nameNow", "en"), g(a, "name", "en")),
      affil_country     = g(a, "country", "en"),
      affil_country_now = g(a, "countryNow", "en")
    ))
  })
})

Organizations (for example, the Red Cross) have no gender or birth data, so questions about people use only rows where type == "person".

people <- laureates_tbl |> filter(type == "person")

Question 1: How has the share of female laureates changed over time?

Description. Women are a small minority of laureates historically. I join prizes to laureate gender, compute the share of female laureates per decade, and then per category.

person_prizes <- prizes_tbl |>
  inner_join(people, by = "laureate_id") |>
  filter(!is.na(gender))

by_decade <- person_prizes |>
  mutate(decade = award_year %/% 10 * 10) |>
  group_by(decade) |>
  summarise(prizes = n(),
            female = sum(gender == "female"),
            pct_female = female / prizes,
            .groups = "drop")

by_category <- person_prizes |>

  summarise(prizes = n(),
            female = sum(gender == "female"),

Question 2: Which countries lost the most laureates (brain drain)?

Description. This question requires joining three tables. For each prize won by a person, I compare the laureate’s birth country (from laureates_tbl) with the country of their first listed affiliation at the time of the award (from affil_tbl). A laureate “moved” if the two differ. I use the countryNow fields for both so that historical names are compared on current borders. Then I compute, per country, how many laureates it lost (born there, affiliated elsewhere), how many it gained (affiliated there, born elsewhere), and the net.

# First listed affiliation per laureate-prize
primary_affil <- affil_tbl |>
  filter(!is.na(affil_country_now)) |>
  group_by(laureate_id, award_year, category) |>
  slice(1) |>
  ungroup()

moves <- prizes_tbl |>
  inner_join(people, by = "laureate_id") |>
  inner_join(primary_affil, by = c("laureate_id", "award_year", "category")) |>
  filter(!is.na(birth_country_now)) |>
  mutate(moved = birth_country_now != affil_country_now)

# Share of laureates who work in a different country than where they were born
moves |> summarise(prizes = n(), moved = sum(moved), pct_moved = moved / prizes) |>

Question 3: How old are laureates when they win, and is it changing?

Description. I compute age at award as award_year - birth_year. I use the birth year only, so ages are approximate to within one year. I compare the distribution by category and look at the trend over time.

ages <- prizes_tbl |>
  inner_join(people, by = "laureate_id") |>
  mutate(birth_year = as.integer(str_sub(birth_date, 1, 4)),
         age = award_year - birth_year) |>
  filter(!is.na(age), age > 0)

Question 4: Which institutions are linked to the most laureates?

Description. Using the affiliation table, I count distinct laureate-prize pairs per institution (so a laureate is not double counted if an institution is listed twice for the same prize). I use nameNow (the institution’s current name) where available, falling back to the name at the time. Then I break the top institutions down by prize category.

inst_counts <- affil_tbl |>
  filter(!is.na(institution)) |>
  distinct(laureate_id, award_year, category, institution) |>
  count(institution, name = "laureates", sort = TRUE)

Conclusion

Nested JSON from the Nobel Prize API can be flattened into tidy tables with jsonlite and purrr, and the interesting questions come from joining those tables, here birth place from the laureate record against affiliation country from the prize record.

Data source: Nobel Prize API v2.1, NobelPrize.org (Nobel Prize Outreach).
