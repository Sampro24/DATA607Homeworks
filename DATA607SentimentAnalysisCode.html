Approach

I first recreated the Chapter 2 example from Text Mining with R (Silge & Robinson) to get a working baseline. The book presents sentiment analysis as a tidy data operation: unnest_tokens() text into one word per row, then inner_join() sentiment scores from a lexicon. I used that workflow for the extension. I swapped out the Jane Austen novels for the State of the Union addresses in the sotu package, and I added the Jockers-Rinker lexicon, along with AFINN, Bing, and NRC. Addresses can be quite long, so I scored each one by net sentiment per 1,000 words. I then compared the four lexicons by plotting their trajectories in time, calculating their correlations, and checking how much of each corpus each lexicon covers.

Challenges

The first challenge is setup. AFINN and NRC now download with the textdata package and require interactive license acceptance, which breaks non-interactive knitting unless the lexicons are cached first. The second is comparability. The lexicons use different scales (−5 to 5, −1 to 1, or binary positive/negative), so I standardized the raw scores to allow direct comparison. The third is domain mismatch. Lexicons were largely built from reviews and tweets, so some words may be scored incorrectly in political speech, just as “miss” is in Austen. The fourth is that unigram methods ignore negation and context, so “not secure” is scored on “secure” alone. The last is that the corpus format has changed over time, from long written messages in the 1800s to spoken addresses later. This can produce apparent trends based on style, not real changes in tone.

Overview

  1. Reproduction. I reproduce the code from Chapter 2, “Sentiment analysis with tidy data,” of Text Mining with R: A Tidy Approach [@silge2017tidytext]. All code in Part 1 comes from the chapter available at https://www.tidytextmining.com/sentiment [@silge2017ch2]. Code is reproduced unchanged except for chunk labels and comments.
  2. Extension. I apply the same approach to a different corpus (U.S. presidential State of the Union addresses) and add an additional sentiment lexicon (the Jockers-Rinker lexicon from the lexicon / syuzhet ecosystem). I then compare my results with those from the original Jane Austen example.

Part 2: Extending the analysis

2.A A different corpus: State of the Union addresses

Corpus. The sotu package [@mullen2020sotu] contains the full text of U.S. presidential State of the Union addresses, along with metadata (president, year, party, and whether the address was spoken or written). This corpus differs from the original example in several ways:

Original (Austen) Extension (SOTU)
Genre 19th-century narrative fiction Political speeches / policy documents
Authors One author Many presidents, over two centuries
Natural unit Novel, 80-line chunk Individual address (varies greatly in length)
Time axis Narrative time Calendar year

Because addresses vary enormously in length (some 19th-century written messages are very long), I normalize sentiment by length rather than using raw sums.

2.B An additional lexicon: Jockers-Rinker

Lexicon The Jockers-Rinker polarity lexicon was originally created by Matthew Jockers for the syuzhet package [@jockers2017syuzhet] and later refined by Tyler Rinker and distributed in the lexicon package as hash_sentiment_jockers_rinker [@rinker2018lexicon]. Like AFINN, it assigns each word a numeric polarity score. Still, the scores range roughly from −1 to +1 rather than −5 to +5, and the word list is much larger than AFINN’s 2477 entries. It was designed to analyze narrative text and thus provides a useful contrast to the review-based Bing lexicon.

How much of each text does each lexicon actually cover?

A lexicon can only rate words that it contains. I compare the percentage of tokens each lexicon matches in the Austen novels (Part 1) with the SOTU addresses.

coverage <- function(tokens, lex, label, corpus) {
  tibble(
    corpus = corpus,
    lexicon = label,
    pct_tokens_matched = mean(tokens$word %in% lex$word) * 100
  )
}

nrc_pn <- get_sentiments("nrc") %>%
  filter(sentiment %in% c("positive", "negative")) %>%
  distinct(word)

lex_list <- list(
  AFINN = get_sentiments("afinn"),

cov_tbl <- bind_rows(

Domain mismatch: words the lexicons may mis-score

“Miss” is a title in Austen, not a bad word, the book notes. Political speech has similar issues. The following words are in the Bing lexicon but may have neutral or institutional meaning in presidential speeches. Conclusion

When we applied the Chapter 2 procedure to State of the Union speeches, the results were broadly similar to the original. The four lexicons vary in size but follow similar trajectories (pairwise correlations 0.74–0.88), and the Jockers-Rinker lexicon added most strongly to the others (0.87–0.88). Unlike the Austen novels, which oscillate between positive and negative over the course of the plot, nearly every address received a net positive score, with sentiments peaking in the 1790s and the 1950s–60s and dipping around 1850. After 1980, the lexicons diverged most, with NRC trending downward and AFINN increasing. Jockers-Rinker had the highest coverage (14.1% of tokens in SOTU). Domain mismatch is a limitation: many of the top positive Bing words (work, right, interests, support, regard) are routine political vocabulary rather than expressions of sentiment, which likely inflates positive scores. The method is unigram-based and therefore ignores negation and context, and shifts between written messages and spoken speeches may explain part of the historical trend.
